Critical Fix Immediately

src/plugins/vcPanelSettings/index.tsx:96-197 Critical

5x useEffect subscription leaks. Each FluxDispatcher.subscribe() call has no cleanup return and no dependency array. Every re-render creates 5 new orphan listeners that live forever.

src/plugins/rpcStats/index.tsx:180 Critical

setInterval never cleared. setInterval(() => ..., 1000) — the interval ID is not stored, and stop() never calls clearInterval. Runs forever after stop().

src/(youcord)plugins/musicControls/tidal/TidalStore.ts:95-139 Critical

WebSocket listener leak. initWs() creates new WebSocket() and adds 4 anonymous addEventListener calls. reconnect() calls initWs() again without closing the old socket — each reconnect = +1 orphan WebSocket + 4 orphan listeners.

src/youcordplugins/macOsButtons/index.tsx:132-184 Critical

Window focus/blur listener leak. window.addEventListener("focus"/"blur", ...) called from MutationObserver callback. No removeEventListener anywhere — listeners accumulate on every reconnect.

soundcloudPlayer/native.ts:241 • youtubePlayer/native.ts:117 Critical

Global click handlers never removable. Anonymous document.addEventListener("click", (e) => {...}, true) — impossible to remove since the function has no reference.

src/youcordplugins/Surveillance/index.tsx:392+ Critical

Stale getState() reads with no subscription. PresenceStore.getState()?.statuses called 3 times (lines 392, 547, 590) in event handlers without any FluxDispatcher.subscribe. Data may be stale; no reactive updates.

High Should Fix Soon

scripts/build/build.mjs High

Duplicate main builds. dist/desktop/patcher.js and dist/youcord/main.js are compiled from the same entry point (src/main/index.ts) with only a single define difference. Build once, copy the other. Saves ~55 MB.

scripts/build/common.mjs:126 High

makeAllPackagesExternalPlugin never used. The plugin is defined but not included in any build config. Every npm dependency (including heavy ones like diff at 507 KB) is inlined into the 55 MB main/patcher bundles. Activating this saves ~50 MB.

dist/ High

Source maps shipped in production. Despite sourcemap: false in commonOpts, ~150 MB of .map files are present in dist/. The config needs to be verified or .map files need to be cleaned up post-build.

scripts/build/buildWeb.mjs High

Monaco editor copied 3x. Monaco (93 MB npm) is bundled into vendor/monaco/ and then copied into chromium-unpacked/ + firefox-unpacked/ = 17.5 MB wasted. Use symlinks or download on first use. Also, Monaco is only used for the QuickCSS editor in web builds — not in desktop at all.

100+ locations High

Inline style={{...}} objects in JSX. Every render creates new object instances. Worst offenders: customProfile/index.tsx (20+), fakePerm/index.tsx (15+), fakeDM/index.tsx (15+), DynamicIslande/index.tsx (10+). Extract to CSS module classes.

dist/*/renderer.css High

CSS produced 6 times. Same 347 KB CSS content appears in desktop/renderer.css, youcord/renderer.css, browser/browser.css, extension.css, Equicord.user.css, plus extension copies. Additionally, the desktop renderer.css statically bundles all Discord CSS — evaluate if deferred loading is possible.

PatchPreview.tsx • patchWebpack.ts High

Dynamic require("diff") prevents tree-shaking. The 507 KB diff package is bundled synchronously via require() instead of lazy import("diff"). It is only used for diffWordsWithSpace in patch preview modals — a rare operation.

platformIndicators/index.tsx:115 High

PresenceStore.getState() in a component render path without subscribing to store updates. Component may show stale data.

Medium Should Refactor

macOsButtons/index.tsx:171 • youcordAI/index.tsx:849-870 Medium

DOM queries inside MutationObserver. document.getElementById() called inside observer callbacks that fire on every body DOM mutation (subtree: true). Inefficient; cache references or use a more specific observer target.

streamProof/index.tsx:84 Medium

Long CSS selector on every click. target.closest("[class*='messageContent_'],[class*='markup_'],...)" — a 14-class selector string evaluated on every document click event across the entire page.

src/youcordplugins/customProfile/index.tsx Medium

Enormous single file. 2,522 lines, 127.9 KB. Loads all profile editing UI eagerly. Split into lazy subcomponents.

src/plugins/commandPalette/registry.tsx Medium

Largest plugin file. 3,839 lines. Eagerly imports 15+ Discord stores at module level. Could use deferred imports.

multiple files Medium

Hardcoded theme colors. fakePerm/index.tsx, fakeDM/index.tsx, abreviation/index.tsx use "#ffffff", "#5865f2", etc. instead of CSS custom properties. Breaks theme compatibility.

15+ locations Medium

style={{ display: "contents" }} pattern. Repeated 15+ times across the codebase. Should be a single CSS class like .vc-display-contents.

src/plugins/snowfall/index.tsx:327-342 Medium

Partial cleanup in stop(). Clears the interval but not the resize/visibility listeners. Only destroy() does the full cleanup.

scripts/build/build.mjs vs buildDesktop.mts Medium

Two divergent build pipelines. build.mjs produces 60 MB outputs, while buildDesktop.mts produces 400 KB using vencordDep from an external asar. Reconcile or migrate to the leaner approach.

src/Vencord.ts:400 Low

src/plugins/musicControls/ Low

29 files, 117.3 KB — large plugin with many eager imports.

src/youcordplugins/voiceMessages/index.tsx:128-149 Low

Good Practices Already in Place

LazyComponent used in 48+ locations — heavy components deferred until first render.

findByPropsLazy / findLazy used in 40+ locations — webpack modules resolved on first property access, not at import time.

extractAndLoadChunksLazy in 12+ locations — webpack chunk loading infrastructure is sound and properly deferred.

25/55 FluxDispatcher.subscribe calls are properly paired with unsubscribe in cleanup functions.

key={index} anti-pattern already fixed in previous performance pass.

Minification + console/debugger dropping enabled in production builds via commonOpts.
